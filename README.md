# IYF S12 - Week 4 JavaScript Practice

This repository contains worked examples for the Week 4 JavaScript lessons:
variables, operators, functions, control flow, arrays, objects, JSON, and the
calculator and student grade tracker mini-projects.

## Run the exercises

1. Open `index.html` in a browser. If you have VS Code Live Server, right-click
   `index.html` and choose **Open with Live Server**.
2. Press **F12** and choose the **Console** tab.
3. Read the output sections in order. The program runs each example when the
   page loads.

## Personalize your answers

In `main.js`, update the learner name, student status, and favorite colors in
the **7.1 Variables** section if needed. The learner age is set to 23.
